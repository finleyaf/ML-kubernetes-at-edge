\section{Predictive Modeling Method}


\subsection{Predictor Design and Training Protocol}

Of the prediction approaches surveyed, linear regression with a sliding window input is the
most appropriate for this context. LSTM-RNNs and ENNs achieve strong accuracy on
complex, non-stationary workloads but impose training and inference costs that are
incompatible with edge resource constraints. ARIMA requires separate model fitting per
time-series and is poorly suited to multi-dimensional, correlated resource metrics. A
sliding-window linear regression, by contrast, produces sub-millisecond inference, requires no
runtime retraining, and is sufficiently expressive for the short prediction horizons relevant to
scheduling decisions (five seconds ahead). When applied to metrics that have been smoothed
by a rolling mean—as is standard in the preprocessing pipeline adopted here—the temporal
dependencies become approximately linear, making the simpler model competitive in accuracy
while remaining deployable on edge hardware. This project therefore adopts linear regression
as the prediction component, integrated with K-means and NSA anomaly detection within a
custom Kubernetes scheduling component.

During validation, window values of (5, 10) and horizon values of (3, 5) were used with the best linear config of window:5 and horizon:3 being the outcome.
